# Стек вызовов, "разделяй и властвуй", QuickSort

Учебный проект по алгоритмам и структурам данных.

## Что реализовано

1. **К1** — рекурсивная функция Фибоначчи + трассировка стека вызовов для n=5.
2. **К2** — рекурсивный поиск максимума через "разделяй и властвуй".
3. **К3** — быстрая сортировка (QuickSort).
4. **К4** — сравнение QuickSort и сортировки вставками + график.

## Анализ

### Фибоначчи
- **Сложность:** O(2ⁿ) — экспоненциальная.
- Для n=5: 15 вызовов функции.
- Стек вызовов растёт до глубины n.

### Максимум (разделяй и властвуй)
- **Сложность:** O(n) — каждый элемент проверяется один раз.
- Массив делится пополам, рекурсивно находится максимум в каждой половине.

### QuickSort
- **Средний случай:** O(n log n).
- **Худший случай:** O(n²) — если pivot всегда минимальный/максимальный.
- **Пространственная:** O(log n) — глубина рекурсии.
